# Code of Conduct

Be kind. Be constructive. Be patient. Assume good faith.

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Harassment, personal attacks, and discrimination are not tolerated
- Disagreement is fine — personal attacks are not
- English is the working language, but broken English is welcome
- Maintainers have final say on scope and direction

Report issues to the repository maintainers via a GitHub issue or direct message.
